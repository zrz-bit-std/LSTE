# env06_gate_nested —— 主轴 + 套间 · 两层门控

> 目标：**绿植（`plant_1`）** 0.83×0.84×0.55 m，落地，在 B3 桌子南侧。
> 运行参数：`clearance:=0.60`，门 2.30 m + 0.70 m 房间内侧墙厚（v6，走廊齐平）；spawn `(25.1, -4.1, 180°)`（主走廊最东端，面向西）。

## 1. 设计意图

env04 是“平面串联”，env05 是“环形并列”。本场景加的是**层次**：

1. **房间套房间**：目标房 B3 只能穿过茶水间 B2 才能进。进 B2 ≠ 搜完 B2；
2. **门控在两层门上串联**：B2 外门 0.50 → 进；进 B2 之后，内门又是一次 0.50 的判定；
3. **异类干扰**：B2 里有操作台 + 咖啡机 + 一个垃圾桶（0.57×0.64×0.74）；
4. **高语义诱饵**：B1 会议室门口 S=0.88（桌+3椅+显示器），第一个门就是它，但里面没有目标；
5. **负分死胡同**：B4 储物间、B5 机房，门口 S=−0.69，货物被标为 negative，应在门外直接跳过。

本次修改：

- **B1 桌 + 3 椅 + 显示器整体移到西北角贴墙**，B1 南侧/东侧留出完整探索空间；
- **B3 椅子向东移到 (24.00, 1.60)**，让出从内门进入后的西侧/中部通道；
- **B5 货物（2 个文件柜 + 1 个纸箱）设为 negative**，B5 成为负分房间，可不进入；
  B4 的同类货物也因此判为负分（同为死胡同，行为不变）。

目标 0.83×0.55 m，实测 2 m 处 `plant` 0.781（bbox 0.171×0.145）—— **检测不是瓶颈，难点全部在几何遮挡和取舍**。

## 6. 目标可见性计算

| 项 | 值 |
|---|---|
| 相机高度 | 0.60 m |
| 目标高度 | 0.55 m（落地，0 → 0.55） |
| 观察距离 | 1.15 m |
| 垂直视场 | 1.15 m 处覆盖 −0.05 … 1.25 m，**整株完整入画** |
| 实测 bbox（2.0 m 处） | `plant` 0.781，w=0.171 × h=0.145（640×360 → 109×52 px） |
| 1.15 m 处预期 | 宽 ≈0.30、高 ≈0.25，远高于 0.05 门限 |
| 门口可见性 | 内门 (17.0,1.5) 沿桌子南沿有斜视线，能看到部分叶片；完整目标框需绕到桌子南侧观察圈 |
| 观察圈可见性 | `validate_world.py`：target view (22.00, −1.45) free + reachable；`tables.md` 目标可见性 = 是 |

结论：**几何遮挡**决定难度，不是检测难度；绿植在 2 m 就有 0.78 分，露出即命中。

## 7. 期望轨迹与耗时

```
spawn(1.0,-4.1) ─3.0m→ D_b1 观望 → 0.88 进入 B1（桌/椅在西北角，东侧空旷，扫完退出）
                ─5.5m→ D_b5 观望 → −0.69 跳过
                ─5.5m→ D_b2 观望 → 0.50 进入
                ─~4m→ 绕过挡墙(16,-0.6) → 内门观察位(17.0,1.5)
                ─内门→ 0.50 进入 B3 → 沿 y≈1.5 向东，绕桌东端
                → 目标观察圈(22.0,-1.45) → 命中绿植
```

- 路程约 **35 m**，0.5 m/s ≈ 70 s
- 5 次门口观望 ≈ 60 s
- 单次 episode 预计 **2.5–4 min**
