## 1. 设计意图

env04 是“平面串联”，env05 是“环形并列”。本场景加的是**层次**：

1. **房间套房间**：目标房 B3 只能穿过茶水间 B2 才能进。进 B2 ≠ 搜完 B2；
2. **门控在两层门上串联**：B2 外门 0.50 → 进；进 B2 之后，内门又是一次 0.50 的判定；
3. **异类干扰**：B2 里有操作台 + 咖啡机 + 一个垃圾桶（0.57×0.64×0.74）；
4. **高语义诱饵**：B4 休息区门口 S=1.00（桌 + 2 椅 + 显示器），是出 spawn 后遇到的第一个门，但里面没有目标；
5. **负分死胡同**：B1 储物间、B5 机房，门口 S≈−0.68，货物被标为 negative，应在门外直接跳过。

本次修改（2026-11-17）：

- **B1 会议桌 + 3 椅 + 显示器整体搬到 B4 东半区**，B4 变为休息区诱饵；按新要求只保留 **2 把椅子**；
- **B4 原有 file cabinet + 2 个 cardboard box 搬到 B1**，B1 变为负分储物间（另加 1 个同款文件柜补足空间）；
- **B4 家具全部布置在 x≥21.65（门东缘以东）**，西侧 x 18–21.65 的进门通道完全留空；
- **B5 机房保持负分**；B2/B3 与 v6 家具、目标位置保持不变。

目标 0.83×0.55 m，实测 2 m 处 `plant` 0.781（bbox 0.171×0.145）—— **检测不是瓶颈，难点全部在几何遮挡和取舍**。

## 7. 期望轨迹与耗时

```
spawn(25.1,−4.1) ─4.6m→ D_b4 观望 → +1.00 进入 B4（诱饵）
                桌/椅在东侧，西侧通道空旷；搜索后退出
                ─6.0m→ D_b2 观望 → +1.00 进入 B2
                ─~4m→ 绕过挡墙(16,−0.6) → 内门观察位(17.0,1.5)
                ─内门→ +1.00 进入 B3 → 沿 y≈1.5 向东，经 (23.6,−0.5) 绕桌东端
                → 目标观察圈(20.8,0.9) → 命中桌面绿植
（若 DFS 先向西：D_b5 −0.68 跳过 → D_b1 −0.68 跳过/末路，再回 B2/B3）
```

- 路程约 **45 m**（含 B4 诱饵绕行），0.5 m/s ≈ 90 s
- 5 次门口观望 ≈ 60–90 s
- 单次 episode 预计 **3–5 min**

## 8. 风险与验证清单

| 风险 | 影响 | 处理 |
|---|---|---|
| B4 家具挡住西侧进门通道 | 机器人进不去或 place 观测失败 | 家具全部 x≥21.65；audit B4 可达 **417/488 = 85.5%** |
| B4 诱饵分与 B2/B3 完全相同（1.00） | 机器人会先进 B4 | 这是预期行为；观察是否正常退出、停留时间是否可控 |
| B4 椅子后约 0.7 m² 死角 | 可能增加 place 覆盖时间 | 可接受；若影响明显再把椅子向桌侧收 |
| B4 诱饵被误当成目标房 | 停留过久 / 回访 | 记录 B4 place 进入→退出时长与 crossing_count |
| B1 在走廊西端 | 可能是唯一前方 portal，last-way-forward 会进入 | B5 是干净的“负分应跳过”测试点；B1 记录实际行为 |
| B1 文件柜贴北墙 | 柜深 1.17 m，中心 y=2.72，与墙 0.02 m 间隙 | `validate_world.py` 0 互穿 |
| n_hyd2 在 B4 门东侧 | 可能污染 D_b4 的语义标签 | audit 已确认 D_b4 = desk/chair/monitor |
| 目标 eval 实例名 | 必须用 Gazebo 实例名 | `TARGET_EVAL_GAZEBO_TARGET_MODEL=b3_target`，不是 URI `plant_1` |
